# iSunOne website archive

Static preservation of the published iSunOne website, captured September 14, 2026, with its original copy, artwork, layout, articles, and language variants.

This is historical material. Business forms, membership, purchases, and unavailable legacy service links are inactive. Statements about products, partners, licensing, availability, or fees describe the archived source and are not a current offer or verification.

The public repository contains only the website presentation and deployment configuration. Private source archives, administrative records, business exports, and credentials are excluded.

Serve locally with `python3 -m http.server 8000`, then open `http://localhost:8000/`. GitHub Pages publishes the `main` branch from its root. Relative links support both the project URL and a custom domain.

Pages carry `noindex` directives. Artwork and content retain their existing ownership and rights; no additional license is granted.
